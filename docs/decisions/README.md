# Decisiones de arquitectura (ADRs)

> Cada feature cerrada deja un registro breve de las decisiones tomadas.
> Formato ligero: contexto, decisión, alternativas descartadas.

## Convención de nombres

`NNN-nombre-corto.md` donde NNN es el id de la feature.

Ejemplo: `001-project-scaffolding.md`

## Plantilla

```markdown
# ADR-NNN: Título

## Contexto
_Qué problema se resolvía._

## Decisión
_Qué se decidió y por qué._

## Alternativas descartadas
_Qué se consideró y por qué no._

## Diagrama (si aplica)
_Mermaid UML._
```
